How it works

Token contracts. We read the verified source and the chain: who the owner is (a wallet, a multisig, a timelock or nobody), whether the code can be swapped (a proxy), and every power that's left: minting, blacklists, pausing, tax switches, trading switches. We also simulate a buy and a sell to catch honeypots. An AI reads the code and explains each power, and every point it makes is tied to a line of code or a chain fact.

Websites. We open the site in a sealed browser with a fake wallet that holds no keys, click its connect and claim buttons, and record everything it asks the wallet to sign: approvals, permits, marketplace orders, transfers. We also check public phishing lists, the domain's age and look-alike names.
