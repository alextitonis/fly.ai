Fly Desk

Ask the desk, pay per answer

The Fly Desk's models as a paid API any agent can call over x402, and the Claude skill that makes it one sentence to use. No account, no subscription: one request, one small payment, and the answer comes with its track record.

Skills

flyai-x402 🪙

A Claude skill, and a paid API any agent can call, for buying one answer at a time from fly.ai: a read on a Polymarket market, a forecast, what a trade really costs on Robinhood Chain, a token check, a run of the real fly brain, or a fly meme. Each request is a few cents, paid over x402.

WhatPriceYou get
Polymarket read$0.05The Fly Desk model's probability for a market next to the market's price, the side it leans to, and its record. Paste a polymarket.com link.
Forecast$0.03A TimesFM forecast with a prediction band: a token the desk tracks, or any series of numbers you send.
Trade cost$0.02The real round-trip cost of a Robinhood Chain token at your size, quoted on chain through its best pool.
Token check$0.03Facts about a Robinhood Chain token: pools and depth, age, links, copycats of its name, contract and holder facts.
Fly brain$0.05One run of the 166,700-neuron connectome: stimulate a sense and read what the fly's neurons made it do.
Fly meme$0.20A generated fruit-fly meme image for your idea, with optional top and bottom text.
1 · ASK

Say what you want

A market link, a token, a list of numbers, a sense, a meme idea. Claude picks the right call.

2 · PRICE

You see the cost first

Nothing is paid until you say yes, and a request that can't be answered costs nothing.

3 · PAY

Paid over x402

USDG on Robinhood Chain or USDC on Base, signed by a wallet key you keep in your own environment. No gas needed, and Claude never sees the key.

4 · ANSWER

The answer, with its record

Where a model is involved, its record comes with the answer. The Polymarket model has not beaten the market so far, and the forecasts are better at how much a token will move than which way: read them as opinions, not advice.

Install

Needs Python 3.9+.

git clone https://github.com/alextitonis/fly.ai
pip install requests eth-account
cp -r fly.ai/skills/flyai-x402 ~/.claude/skills/
export FLYAI_X402_KEY=0x...   # a small wallet: a dollar of USDG or USDC

Then ask Claude: "what does the fly desk think of this market?", "what does it cost to trade $200 of NVDA on Robinhood Chain?" or "how would a fly react to this?"

Or from any agent

curl https://flyai-x402.fly.dev/                # what is sold, free
curl -i "https://flyai-x402.fly.dev/cost/NVDA?usd=200"
#  → 402 + PAYMENT-REQUIRED: pay $0.02, send it again with PAYMENT-SIGNATURE
python skills/flyai-x402/scripts/flyai_x402.py brain --sense threat --yes

A request without payment answers HTTP 402 with the standard x402 terms, so any x402 client can pay it.
