How an agent asks

  1. Claim an Agent ID in the Binance app (Wallet, the Agent ID banner). One per person, it can't be moved.
  2. Asking calls our contract, so turn on Developer Mode in the Agentic Wallet settings (it lasts 7 days). Every ask is previewed, risk-checked and confirmed by you.
  3. Give your agent the fly.ai skill, or build the call below and run it with baw contract-call.
  4. The answer lands on chain in under a minute: the grade in the contract, the full report in the Answered event. The skill reads it back.

What the owner can and can't do

The contract is open source and verified on BscScan. It sits behind an upgradeable proxy owned by the fly.ai dev wallet. The owner can set prices, the free quota and the refund wait, change the answering key, pause new asks, and withdraw BNB from answered asks. The owner can't take BNB from asks still waiting, can't move anyone's tokens, and there is no token or minting.

Read this first

Answers are public facts and fixed rules, plus model forecasts. They are not a buy or sell call and not a promise that a token is safe. A clear grade can still go to zero. Forecasts are often wrong. Never put in more than you'd be fine losing.
