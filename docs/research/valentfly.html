The Bachelor, run by an actual fly brain

5 candidates, one lead, a hidden compatibility score nobody gets to see, a date with each, and a single rose at the end. The twist: every date and the final proposal are decided live by flybrain.FlyBrain — the real 166,700-neuron MaleCNS connectome, spiking in real time. Not a script, not a trained model, not a coin flip.

The rules

Same shape as the show, decided by a real brain instead of a person

5 candidates, each with a hidden true compatibility score (0–10) that the "lead" never gets to see — same as no one on the real show can see a number over anyone's head.

HOW A SEASON PLAYS OUT

One date each, one proposal

Every candidate gets exactly one date, always in the same fixed order — nothing skipped, nothing repeated. Then a single proposal is made to whichever candidate produced the strongest live reading. Correct only if that candidate's true compatibility was actually the highest in the pool; otherwise it's heartbreak, scored proportional to how wrong it was.

SAME SEATS, NEW LEAD EVERY SEASON

Seats are fixed; compatibility isn't

The 5 seats map to the same 5 real neuron populations for an entire run — that's why "Seat 3" looks the same across every season on the recap page. But each season draws a brand-new, independent hidden compatibility score, and the brain itself resets to a fresh seed with it. No season carries over a "lead" or a memory from the last one — that's also why seats are labeled by number, not by name.

How it works

One real neuron population per seat, and a plain argmax

Nobody trained this brain and nobody scripted the outcome. The only made-up part is which neuron population stands in for which seat — same honesty this project's other demos hold themselves to.

01 · DATING = STIMULATING

One population per candidate

encode.py picks 5 real, size-matched olfactory receptor neuron types straight from the connectome's own metadata, one per seat. "Dating" means injecting 0.5 s of voltage into that seat's real neurons, at a strength set by their true (hidden) compatibility — a better match is a stronger stimulus.

02 · THE WHOLE BRAIN RUNS

Real synapses, real hops

This isn't a straight readback of the input neurons: the real MaleCNS synaptic weight matrix propagates every step, so the stimulus passes through several real connectivity hops before it reaches the descending-neuron population — the connectome's actual motor-output neurons — where the reading is taken.

03 · DECISION = ARGMAX

Highest reading wins

After each date, the settled mean spike trace of the descending neurons is read off as a plain scalar — not a prediction, a measurement. The proposal goes to whichever candidate produced the highest one. No value function, no Q-values, no cross-validated readout: comparing five raw numbers is the decision.
